# PDF 转 Word

打开 PDF 或图片后，都可选择“导出 Word”。导出使用当前编辑快照，包含新增文字、涂抹及印章，不修改原文件。PDF 保留全部页面；图片先在内存中生成单页 PDF，再复用同一转换流程。

## 设置与结果

- 默认“可编辑优先”：保留各页尺寸、分页与文字位置，按行生成可编辑的 Word 定位段落；图形、图片和表格线作为页面背景保留。
- “外观优先”：每页作为图片放入 DOCX，文字不可直接编辑。
- 文字来源可选自动提取并补充识别，或全部使用 OCR；后者适用于文字编码异常的 PDF。
- 支持简体中文、英文和中英混合识别，复用 `public/ocr-assets` 中的本地语言包。
- 页码范围留空表示全部页面，支持 `1-3, 5`，重复页码去重后按原文顺序导出。
- 清晰度为 144、216 或 300 DPI。为限制浏览器内存，单页栅格化最多约 800 万像素，超大页面会降低实际分辨率。
- 进度按读取、逐页识别与排版、DOCX 打包推进；转换中可取消。成功后自动触发下载，并保留“下载 Word”链接，便于移动浏览器或拦截自动下载时手动保存。

## 转换策略

1. 用 PDF.js 读取页面尺寸和文字层，保留可用文字的位置、字号、基础粗体/斜体和采样颜色。
2. 重新渲染不含文字绘制指令的背景。对比原图过滤不可见文字层，避免可搜索扫描件出现重复文字。
3. 对剩余可见内容做 OCR，识别扫描图片、转曲文字和原生页内的扫描片段。中文使用行级文字框，避免 OCR 单字框交叉导致字号和基线错误。
4. 根据识别行的范围清除原图文字，再叠放可编辑文字；尽量保留跨越文字区域的表格线。当前工作台添加的印章区域不做 OCR 替换。
5. 生成真正的 OOXML DOCX，使用 fflate 打包；PDF/OCR/Word 导出依赖按需加载。OCR 运行于专用 Worker，取消、加载错误、超时和卸载会终止该任务的 Worker。

整个流程在浏览器内运行，不调用第三方转换服务。开发接口参考：[PDF.js](https://mozilla.github.io/pdf.js/api/)、[Tesseract.js](https://github.com/naptha/tesseract.js)、[Word 定位段落](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.frameproperties)。

## 保真边界

- 这是按页面位置重建的可编辑文档，不是语义完整的排版恢复。文字以定位段落为主，大幅修改文字后可能需要手动调整位置。
- 复杂表格不会重建为 Word 表格，公式、图表及部分无法识别的内容保留为图像；原有阅读顺序、字体和字符样式可能发生变化。
- 扫描和转曲内容的 OCR 可能有错字、漏字，识别出的字体与原字体不一定一致。彩色底纹、文字与图片交叠、倾斜、竖排或旋转文字的效果需要人工复核；无法可靠直接提取的文字会转入 OCR。
- 原文件内已经存在的印章、图片中的装饰文字仍可能被 OCR 当作正文；工作台本次添加的印章有单独保护区域。
- Word 最大页面尺寸为 22 英寸，超过的页面与其内容会等比缩小。累计背景图与文档 XML 超过 120 MB 时中止并提示缩小页码范围，避免浏览器内存过高。
- 关闭弹窗会释放下载链接。文件、转换结果和设置不持久化保存。

## 验证

自动回归：`node --test tests/wordExport.test.mjs`，覆盖页码边界、混合文字去重、中文行框、OOXML 页面/图片关系/文本转义、超大页面和取消。受限环境不允许测试启动子进程时，Node 22.8+ 可用 `node --test --test-isolation=none tests/*.test.mjs`。

浏览器人工验收可依次使用原生文字 PDF、中文扫描件、同页原文与扫描图、转曲文字、带隐藏文字层的扫描件：

1. 检查 PDF 和图片均显示导出入口，并验证设置、进度、自动下载与手动下载。
2. 输入越界页码，确认提示后可以重试；在识别中取消，确认任务退出后仍能转换。
3. 在 Word 中打开结果，核对页数、横竖页尺寸、表格线及中文行位置，并编辑其中的文字。
4. 对 PDF 和图片分别添加文字、涂抹及印章后导出，检查编辑结果保留；验证 OCR 使用当前编辑版本。
5. 在窄屏及深色模式下检查弹窗滚动与操作按钮。

开发时已用 Chrome 合成样例验证原生页、中文扫描、混合横向页、矢量转曲和隐藏文字层；前四类样例已通过本机 Word 页面图元预览核对分页及文字位置。实际业务 PDF、其他 Word/WPS 版本及手机上的文件保存仍需分别验收。
